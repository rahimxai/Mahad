# images/

Place your photos in this folder.

## Required
| File           | Description                                         |
|---------------|-----------------------------------------------------|
| `mahad.png`   | Your portrait photo for the hero section            |

## Tips for the best result (hero "text-behind-person" effect)
- Export your photo as **PNG with a transparent background** (background removed).
- Use tools like **remove.bg**, **Photoshop**, or **Adobe Firefly** to remove the background.
- A full-body or half-body shot works best (portrait orientation).
- Recommended minimum size: **800 × 1200 px**.

## Additional images (optional)
You can also add project thumbnail images here and reference them in `index.html`
if you want to show static thumbnails instead of embedded YouTube iframes.
